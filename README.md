# LLM Comparison Tool 🚀

This project was developed as part of a **college training session** focused on learning modern Python development practices, API integration, and basic application deployment concepts.

The goal of this project is to **compare responses from multiple Large Language Models (LLMs)** using a **single unified prompt**, and display the results side by side using a simple web interface built with **Streamlit**.

---

## 📌 Project Overview

During the training session, we explored:
- Working with **external APIs**
- Managing **environment variables securely**
- Running tasks **in parallel** using Python
- Structuring a Python project cleanly
- Building a basic interactive UI with **Streamlit**
- Generating downloadable reports

This tool currently compares:
- **ChatGPT (OpenAI)**
- **Gemini (Google Generative AI)**

---

## 🛠️ Technologies Used

- **Python 3.9+**
- **Streamlit** – UI framework
- **OpenAI API** – ChatGPT responses
- **Google Generative AI API** – Gemini responses
- **pandas** – Report generation
- **python-dotenv** – Environment variable management

---

## 🔑 Required API Keys

This project requires **two API keys**:

### 1️⃣ OpenAI API Key (for ChatGPT)
- Create an account at: https://platform.openai.com/
- Generate an API key

### 2️⃣ Google Gemini API Key
- Create a project in Google AI Studio
- Generate a Gemini API key

---

## 🔐 Environment Variables Setup

Create a `.env` file in the project root:

```

OPENAI_API_KEY=your_openai_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here

````

⚠️ **Important:**  
The `.env` file and API keys are ignored using `.gitignore` and should never be committed to GitHub.

---

## 📦 Required Python Packages

Install all dependencies using:

```bash
pip install streamlit openai google-generativeai python-dotenv pandas
````

Or using a virtual environment (recommended):

```bash
python -m venv env
env\Scripts\activate
pip install streamlit openai google-generativeai python-dotenv pandas
```

---

## ▶️ How to Run the Project

From the project root:

```bash
streamlit run app.py
```

This will start a local server and open the app in your browser.
